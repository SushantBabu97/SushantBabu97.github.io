## AsterConsult: CRM Solution for Study Abroad Ecosystem

A multitenant SaaS platform designed specifically for the study abroad industry.

### What I Built

- **Planned, Designed, and Architected** a comprehensive CRM solution for study abroad consultancies
- **Implemented Domain-Driven Design** with Hexagonal Architecture for clean, maintainable code
- Built a multitenant SaaS product supporting multiple organizations with data isolation

### Tech Stack

- **Backend**: GoLang, PostgreSQL, NATS messaging
- **Frontend**: React
- **Infrastructure**: Caddy Control, Casbin (RBAC), PocketBase
- **Architecture**: Domain-Driven Hexagonal Architecture

### Key Features

- Multi-tenant application with separate data contexts
- Role-based access control (RBAC)
- Event-driven architecture using NATS
- RESTful API design
