## Bidhyarthi: Global Education Guidance Platform

An AI-based platform helping students navigate the study abroad process with clarity, providing personalized guidance and process optimization.

### Purpose

- Guide students through the complexities of pursuing education abroad
- Provide AI-powered recommendations and insights
- Optimize and simplify the application and planning process

### Tech Stack

- **Backend**: Node.js, TypeScript
- **AI/ML**: Generative AI using Google Genkit framework
- **Database**: PostgreSQL with PGVector for vector embeddings
- **Features**: Semantic search, AI recommendations

### Key Features

- AI-powered student guidance system
- Vector embeddings for intelligent search and recommendations
- Process optimization for study abroad applications
- Personalized recommendations based on student profile
