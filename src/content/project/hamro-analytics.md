## Hamro Analytics: User Event & KPI Tracking System

A comprehensive data warehousing and analytics platform designed to handle millions of data points from 2M+ users daily, providing insights for operation and management teams.

### Scale & Impact

- Processes millions of data points daily
- Serves 2M+ users per month
- Enables data-driven decision making for operations and management

### What I Built

- **Data Pipelines**: Designed and implemented robust data ingestion pipelines
- **Data Warehousing**: Built scalable warehouse infrastructure
- **Analytics & Visualization**: Created analytics systems with custom dashboards
- **Open Source Integration**: Researched and implemented cutting-edge solutions

### Tech Stack

- **Message Queue**: Apache Kafka for event streaming
- **OLAP Database**: Apache Pinot for real-time analytics
- **Query Engine**: Trino for distributed querying
- **Visualization**: Apache Superset for BI dashboards
- **Data Orchestration**: Mage AI for workflow management
- **Object Storage**: MinIO for data lake
- **Time-Series DB**: Scylla DB for high-performance storage

### Key Features

- Real-time event tracking and processing
- Multi-dimensional KPI analysis
- Custom dashboards for different stakeholders
- Scalable data pipeline architecture
- Time-series data optimization

Planned and constructed data pipelines, data warehousing, and data analytics and visualization systems for user
events and KPI analytics.
Analyzed millions of data points across services from more than 2 million users per day to assist the operation
and management teams in market research and further planning.
Researched and Implemented Open Source projects such as Apache Pinot, Apache Superset, Trino, Mage AI,
MinIO, Scylla DB.
