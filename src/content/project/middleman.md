## Middleman: Job Marketplace Platform

A mobile-first marketplace platform connecting job providers and seekers in a unified ecosystem with real-time communication capabilities.

### What It Does

- Connects job seekers with job providers on a single platform
- Provides real-time messaging for negotiation and updates
- Mobile-first experience for both roles

### Tech Stack

- **Backend**: FastAPI (Python)
- **Mobile**: Flutter (iOS & Android)
- **Real-time Communication**: WebSocket for bi-directional messaging
- **Architecture**: RESTful API with real-time extensions

### Key Features

- Dual-role mobile application (job seekers and providers)
- Real-time in-app messaging system
- Job discovery and matching
- Provider profiles and ratings
